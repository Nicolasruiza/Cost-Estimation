# Initiative Cost Estimator

Interactive browser-based estimator for modeling initiative delivery cost across existing team members, new hires, vendors, and supporting teams.

## What it models

- Existing and new team capacity
- FTE and contractor rates
- Vendors and supporting teams
- CAPEX / OPEX allocation
- Delivery duration and sprint-based costing
- Expense forecasts by sprint, week, month, or quarter
- Downloadable HTML estimate output
